📋 安装步骤

  1. 把下面的按钮 拖到 Chrome 书签栏
  2. 打开任何你想要反馈的本地页面（如 localhost:8088）
  3. 点击书签栏的 GA反馈
  4. 右下角出现 📝 按钮 → 框选元素 → 输入意见 → 收集多条 → 发送

使用说明

  • 🔲 框选元素 — 鼠标移到元素上高亮，点击选中，输入修改意见
