## Tool Auto-Use Rules (2026-06-23)
- **codegraph 自动触发**: 需要关系型理解（调用链/影响范围/依赖图）时自动用，不等用户要求
  - `query` → 快速定位 symbol 文件位置
  - `impact` → 改之前评估波及范围（BFS 3 层）
  - `callers`/`callees` → 追踪跨包调用链
  - 简单事实查读（已知位置/小项目/刚读过）→ 直接 file_read，不用 codegraph
- **rtk 自动触发**: 检测到自重复/低信息密度时自动调用 filter/dynamic
- **报路径规则**: 所有 file path 必须给 full path，不用相对路径或缩写。用户特地强调，牢记
- **文档存放规则**: 文档放到**对应项目目录**的 `output/<topic>/` 子文件夹，如 `projects/migration-dashboard/output/custom-cli/`
- **文件命名规则**: `<project>_<description>_<YYYYMMDD>_v<version>.<ext>`，如 `migration-dashboard_custom-cli-optimization-plan_20260623_v1.md`
- **版本迭代**: 每版必须独立文件（不原地 patch 已有版本）。v3 → v3.1 要新建 `..._v3.1.md`
